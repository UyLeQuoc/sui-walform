## Known issues & deferred items

- **Marketplace listing discovery is stop-gap.** `useTemplateListing` walks recent `create_listing_and_share` txs; will need a proper indexer or registry shared object at scale. Acceptable for hackathon.
- **Marketplace Kiosk paths are dead code in Move source.** `place_and_list`, `purchase_template`, `purchase_template_and_share` are marked DEPRECATED but kept in `template.move` because Sui `compatible` upgrade rules don't allow removing public functions. Client never calls them; the deployed bytecode keeps them callable in principle but no UI surface ever does. Future fresh-publish (if ever) can drop them — until then they're carrying weight only.
- **Vote tracker discovery is event-scan stop-gap.** `useMarketplaceVotes` queries the last 100 `TemplateVotesInitialized` events; older trackers fall off. Same scaling caveat as `useTemplateListing`. Production needs an indexer or a shared `VoteRegistry` table. Acceptable for hackathon.

Creators of legacy templates can call `voting::init_template_votes(template)` post-hoc themselves to backfill, but there's no UI for that yet (deferred — testnet has 0 affected templates).
- **`useTemplateListing` won't find listings older than 50 txs.** Bump limit + paginate when needed.
- **Sealed schema active for Private forms.** Set `NEXT_PUBLIC_ENABLE_SEALED_SCHEMA=true` in `apps/builder/.env`. Marketplace templates still publish with plaintext schemas — the contract's `seal_approve_read_template_schema` policy restricts decrypt to the template creator only, so encryption would prevent buyers from previewing pre-clone (deferred until policy v3).
- **Pre-republish forms are orphaned.** A fresh `contracts:publish` on 2026-04-26 (forced because `c83d693` changed public function signatures, so `contracts:upgrade` rejected with `IncompatibleUpgrade`) reset `originalPackageId`. Seal identity namespace is keyed on `originalPackageId` — every form/submission published under earlier packageIds can no longer decrypt.
